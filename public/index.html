유종
연결 확인 중실제 주유소 데이터 조회 설정을 확인하고 있습니다.

실제 주유소 데이터 연결하기

  1. Kakao Developers ↗에서 주소 검색에 사용할 REST API 키를 준비하세요.
  2. 오피넷 ↗에서 ‘반경 내 주유소’ API를 사용할 인증키를 준비하세요.
  3. 프로젝트의 .env.example을 .env로 복사하고 두 키를 입력하세요. 키를 이 화면이나 채팅에 붙여 넣을 필요는 없습니다.
  4. 서버를 다시 실행하고 이 페이지를 새로고침하세요.

설정 전에는 주유소 가격이 표시되지 않습니다. 상세한 순서는 프로젝트의 README.md에 있습니다.
